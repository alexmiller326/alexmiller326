资深底层系统与安全工程师，专注于构建高可靠低层工具、高性能运行时与形式化验证的密码学协议。工程核心立足于第一性原理架构、二进制取证与零开销系统工程。

### 🛠️ 核心技术栈
- **系统与编程语言**: Rust, 现代 C++ (C++20), Go, TypeScript, x86_64 / ARM64 汇编.
- **安全与取证**: PE32+ / ELF64 解析引擎构建, 内存安全数据流分析, 常数时间密码学实现 (AEAD, Ed25519, Kyber ML-KEM).
- **网络与协议**: 原生二进制网络包解码器, PCAP 流式重组, TLS 1.3 握手遥测与特征指纹 (JA3/JA3S).
- **基础设施与操作系统**: Linux 内核接口, Windows 内部机理与 Authenticode, 跨平台 POSIX 兼容性.

### 🔬 研究与前沿方向
- 无外部依赖的高吞吐流式提取与容器解码器设计.
- 基于 Zeroize 的内存安全清除保证与缓存计时侧信道防御.
- 确定性验证测试框架、模糊测试（Fuzzing）流水线与可重现构建.

### 🧭 工程准则
- **第一性原理设计**: 在编写代码之前，深入理解底层硬件、内核边界与内存布局.
- **零开销抽象**: 追求极致的运行效率，充分利用编译器保证与编译期计算.
- **正统工匠精神**: 编写严谨、高可读且经受严格机械化测试的现代化长效代码.
