Ingeniero senior de sistemas y seguridad dedicado al desarrollo de herramientas de bajo nivel robustas, entornos de ejecución de alto rendimiento y protocolos criptográficos verificados. Mi enfoque se basa en la arquitectura de software de primeros principios, el análisis forense binario y la ingeniería sin sobrecarga de rendimiento.

### 🛠️ Pila Tecnológica
- **Sistemas y Lenguajes**: Rust, C++ Moderno (C++20), Go, TypeScript, Ensamblador x86_64 / ARM64.
- **Seguridad y Análisis Forense**: Motores de análisis PE32+ / ELF64, análisis de flujo de datos con seguridad de memoria, criptografía en tiempo constante (AEAD, Ed25519, Kyber ML-KEM).
- **Redes y Protocolos**: Decodificadores a nivel de cable, reensamblado de flujos PCAP, telemetría y huellas digitales TLS 1.3 (JA3/JA3S).
- **Infraestructura y SO**: Interfaces del kernel de Linux, arquitectura interna de Windows y Authenticode, compatibilidad POSIX multiplataforma.

### 🔬 Investigación y Enfoque Actual
- Decodificadores de contenedores y extracción de flujos de alto rendimiento sin dependencias externas.
- Garantías de borrado seguro de memoria con Zeroize y mitigación de canales laterales de tiempo de caché.
- Arneses de verificación deterministas, pipelines de fuzzing y compilaciones reproducibles.

### 🧭 Principios de Ingeniería
- **Diseño de Primeros Principios**: Comprender el hardware subyacente, límites del kernel y diseños de memoria antes de escribir código.
- **Abstracción de Cero Sobrecarga**: Aprovechar las garantías del compilador frente a sobrecostes en tiempo de ejecución.
- **Artesanía Ortodoxa**: Software idiomático, legible y exhaustivamente probado para perdurar en el tiempo.
