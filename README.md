### 🇺🇸 English

<details open>
<summary><b>🇺🇸 English Overview (Click to expand / collapse)</b></summary>
<br>

I am a senior systems and security engineer focused on building robust low-level tooling, high-performance runtimes, and verified cryptographic protocols. My work centers on first-principles software architecture, binary forensics, and zero-overhead systems engineering.

#### 🛠 Core Technical Stack
- **Systems & Languages**: Rust, Modern C++ (C++20), Go, TypeScript, x86_64 / ARM64 Assembly.
- **Security & Forensics**: PE32+ / ELF64 parser engineering, memory-safe data flow analysis, constant-time cryptography (AEAD, Ed25519, Kyber ML-KEM).
- **Networking & Protocols**: Wire-format packet decoders, PCAP stream reassembly, TLS 1.3 telemetry & fingerprinting (JA3/JA3S).
- **Infrastructure & OS**: Linux kernel interfaces, Windows internals & Authenticode, cross-platform POSIX compatibility.

#### 🔬 Research & Current Focus
- High-throughput stream carving and container decoders without external dependencies.
- Zeroize memory wiping guarantees and cache-timing side-channel defenses.
- Deterministic verification harnesses, fuzzing pipelines, and reproducible builds.

#### 🧭 Engineering Principles
- **First-Principles Design**: Understand the underlying hardware, kernel boundaries, and memory layouts before writing code.
- **Zero-Overhead Abstraction**: Leverage compiler guarantees and compile-time evaluation over costly runtime overhead.
- **Orthodox Craftsmanship**: Write idiomatic, readable, and exhaustively tested software designed to endure.

</details>
